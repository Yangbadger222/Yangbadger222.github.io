# Jiahan Yang / Field Notes

这是 `Yangbadger222.github.io` 的个人主页：以手工档案、工程草图和轻微颗粒感组织机器人、感知与导航项目。页面内容保留远端仓库原有的 About / Work / Research / Code 结构，五张项目图按实际主题对应到各章节。

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 文件说明

- `index.html`：页面结构、项目叙事与 GitHub 链接
- `styles.css` / `visuals.css`：响应式视觉系统、纸张纹理与布局
- `script.js`：插画加载和 GitHub 仓库列表（带本地缓存）
- `assets/*.webp`：主页使用的五张压缩项目手绘图；同名 PNG 原图保留作素材备份

站点不依赖构建工具，可直接将仓库设置为 GitHub Pages 的静态源。
